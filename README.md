# BoxerDash v3 · 纸片拳王 PAPER FIST 🥊🎵

以一张**拼贴画拳击手**（红拳套 · 星条拳裤 · 白色拳靴）为主角的**侧视拳台节奏游戏**。
主角与对手都是把拼贴原画**剪纸分件后绑上 2D 骨骼**的纸片木偶：出拳、受击、闪避、
倒地、胜利全是骨骼动画，待机时跟着节拍弹跳、点脚、晃脑袋。

纯 HTML5 Canvas + Web Audio，零依赖、无构建步骤。
（因为要加载剪纸部件 PNG，请用 `start.command` 或本地服务器打开，见下文「运行」。）

## 玩法（2×2 方位键位）

拳手站在拳台左侧，蓝方对手在对面压步逼近、晃架挑衅。四条航道的**拳靶**从右侧飞来，
在对手身上的命中圈按对按键，主角就打出对应的拳——拳峰会实打实地砸在对手身上。

键位是 2×2 方位网格，和拳位一一对应：上排打头、下排打肚子；左列左手、右列右手。

| 按键 | 拳法 | 伤害倍率 |
|---|---|---|
| `U` | 刺拳 · 高位（左手） | ×1.0 |
| `I` | 直拳 · 高位（右手） | ×1.2 |
| `J` | 勾拳 · 低位（左手） | ×1.45 |
| `K` | 上勾 · 低位（右手） | ×1.6 |
| `ESC` / `P` | 暂停 · `M` 静音 | — |

- 判定分 **PERFECT / GREAT / GOOD**，越准分越高；漏拳扣体力、断连击。
- **连击条（"连"字链球）**：按住对应键不放，拳头自动连打；提前松手断连击。
- **金拳套（星星）**：按对应车道键吃掉 +500，并给金手套槽充能。
- 攒满金手套槽触发 **🔥 金手套时间**：9 秒双倍得分、伤害 1.8 倍、金色演出。
- **对手 K.O. 槽**：把当前对手打空 → 慢镜头倒地 +1000×阵数，下一阵对手更硬。
  对手不是木桩——他每 4 拍就压步还两拳，被打狠了会踉跄、冒星星。
- 体力被打空会被击倒判负；全程无 MISS 通关点亮 **FULL COMBO**。

## 打击感全家桶

命中瞬间：**顿帧**（画面几乎冻结约 45~75ms）→ **震屏** → **拳套闪白 + 弹性放大** →
**纸屑飞溅**（拼贴纸片）→ **星形冲击 + 冲击环** → **速度线** → 随机漫画拟声词
（BAM! / POW! / WHAM!…）→ 对手后仰、飘伤害数字、头上冒星星。连击每 +50 观众席
亮一轮相机闪光。音效层：破空声 + 皮面拍击 + 重量低频三层叠加。

## 三首曲目 × 三档难度

| 曲目 | BPM | 风格 | 配色 |
|---|---|---|---|
| 🥊 钢铁脚步 Steppin' Steel | 128 | 重型 boom-bap（808 + 厚低音） | 深青拳馆 |
| 🏆 拳台之夜 Fight Night | 144 | 安达卢西亚下行 + 铜管 stab + 回合钟 | 拳馆暮色 |
| 🔥 最后一战 Final Round | 160 | 高速强袭，高压连打 | 冠军红 |

难度：**热身 / 挑战 / 冠军**（谱面密度、拳速、受伤系数不同）。
每首 × 每难度的最佳成绩与评级自动存档（localStorage）。

## 音乐

Web Audio 实时合成的原创拳击配乐：鼓组（kick/snare/clap/hat/808）、
铜管味失谐锯齿 stab、回合钟（非谐波分音钟声）、侧链泵感、附点回声。
谱面与音频时钟严格同步，暂停用 `ctx.suspend()`，恢复零漂移。

## 纸片骨骼系统（js/rig.js）

原画按剪纸逻辑切成 **7 个部件**（躯干补丁板 / 头 / 左大臂 / 左拳套 / 右整臂 / 左鞋袜 / 右鞋袜），
绑成层级骨骼。`createRig()` 是工厂函数，实例化出**红方主角**与**蓝方对手**
（对手用同一套部件的镜像 + 换色版本，肩甲等防散架处理完全一致）：

```
root(髋) ── body(躯干,呼吸/侧倾)
             ├── head(颈)              头部晃动
             ├── armLu(肩甲下缘) ── gloveL(肘)   后手两段臂：刺拳/勾拳
             ├── armR(肩,含拳套)                前手整臂：直拳/上勾
             ├── shoeL(踝) ── shoeR(踝)          节拍点脚
```

- 左臂上段（三角肌）烘焙在躯干上当**肩甲**：出拳时手臂从肩甲下缘甩出，
  躯干轮廓不会破洞——纸片人不散架的关键。
- 出拳 = 关键帧动作（windup → strike → recover，impact 帧即拳头命中帧），
  判定圈的位置由骨骼命中帧反算，纸片拳头永远打在判定点上（= 对手身上）。
- 待机为程序动画：节拍弹跳、摇摆、头部晃动、左右脚交替点脚；对手还会定期还拳挑衅。

## 运行

- **macOS**：双击 `start.command`（自动起本地服务器并打开浏览器）。
- 或手动：`python3 -m http.server 8777` 后访问 <http://127.0.0.1:8777/>。
- 触屏设备：左半屏上/下 = J/U，右半屏上/下 = K/I。

## 调试辅助

- `?auto=1` 自动演奏模式（演示/截图用）。
- `?testclock=1` 40 倍速静默时钟（脚本化跑完整局）。
- `rigtest.html` 骨骼测试台：单独查看待机/各拳法/胜利/击倒姿态与命中点。
- 控制台 `window.__boxer`：`info() / nearest() / start(曲, 难度)`。
